## How to run the game

### Compilation

To compile the game, run the following command from the root of the project:

```bash
javac -d bin -sourcepath src/main/java src/main/java/ch/epfl/cs107/play/Play.java
```

### Execution

To run the game, execute the following command from the root of the project:

```bash
java -cp "bin:src/main/res" ch.epfl.cs107.play.Play
```
